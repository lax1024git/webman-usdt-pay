# 数据库设计 — USDT 充付系统

**Version**：V1.0  
**Date**：2026-08-19  
**引擎**：MySQL 8.0+ / InnoDB / utf8mb4_unicode_ci  
**金额类型**：`DECIMAL(20,6)`，应用层 `bcmath` 运算

---

## 1. ER 关系概览

```
pa_merchants 1───N pa_merchant_accounts
pa_merchants 1───N pa_deposit_orders
pa_merchants 1───N pa_withdraw_orders
pa_merchants 1───N pa_merchant_ledger
pa_merchants 1───N pa_webhook_logs

pa_platforms 1───N pa_deposit_orders
pa_platforms 1───N pa_withdraw_orders

pa_deposit_orders 1───1 pa_wallet_addresses (可选)
pa_deposit_orders 1───N pa_chain_transactions
pa_withdraw_orders 1───N pa_chain_transactions

pa_wallet_addresses N───1 pa_platforms
pa_collection_tasks N───1 pa_wallet_addresses
```

## 4. 订单号规则

| 类型 | 格式 | 示例 |
|------|------|------|
| 入金 | `D` + yyyyMMddHHmmss + 6位序列 | D202608191205000001 |
| 出金 | `W` + yyyyMMddHHmmss + 6位序列 | W202608191205000001 |
| 商户号 | `M` + 8位数字 | M10001001 |

序列通过 Redis `INCR pay:seq:deposit:{minute}` 或 DB 序列表生成，保证唯一。

每个表对应 `app/model/pay/XxxModel.php`，实现 `tableSchema()` 后执行：

```bash

```

详见 [模型规范.md](./模型规范.md)。

## 7. 迁移与历史兼容

`config/field_renames.php` 中旧表名映射：

| 旧表 | 新表 | 主要字段对应 |
|------|------|--------------|
| pa_recharge_order | pa_deposit_orders | coin_amount→amount, transaction_hash→tx_hash |
| pa_withdraw_order | pa_withdraw_orders | withdraw_amount, payout_amount, paid_at |
| pa_platform | pa_platforms | min_recharge_amount→min_deposit_amount |

新系统 **不自动迁移** 旧数据；若需导入，单独编写 `php webman pay:import-legacy` Command。
