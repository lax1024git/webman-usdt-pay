# 模型规范 — USDT 充付系统

**Version**：V1.0  
**Date**：2026-08-19

---

## 1. 总则

- 业务模型置于 `app/model/pay/`  
- 系统模型保持 `app/model/sys/`，前缀 `sy_*`  
- 支付业务表统一前缀 **`pa_*`**  
- 每个模型必须：
  - `declare(strict_types=1);`
  - `use DefinesTableSchema;`
  - 实现 `public static function tableSchema(): array`
  - 金额字段在 `$casts` 中 **不要** cast 为 float，保持 string 或使用自定义 Decimal cast

---

## 2. 命名规范

| 类型 | 规范 | 示例 |
|------|------|------|
| 模型类 | 单数 + Model | `DepositOrderModel` |
| 表名 | 复数 snake | `pa_deposit_orders` |
| Service | 单数 + Service | `DepositOrderService` |
| Controller | 单数 + Controller | `DepositOrderController` |
| 常量 | 大写下划线 | `STATUS_PENDING` |

## 3. tableSchema 模板

```php
<?php

declare(strict_types=1);

namespace app\model\pay;

use app\model\Concerns\DefinesTableSchema;
use Illuminate\Database\Eloquent\Model;

class DepositOrderModel extends Model
{
    use DefinesTableSchema;

    public const STATUS_PENDING = 'pending';
    public const STATUS_DETECTING = 'detecting';
    public const STATUS_SUCCESS = 'success';
    public const STATUS_EXPIRED = 'expired';
    public const STATUS_FAILED = 'failed';
    public const STATUS_MANUAL = 'manual';

    protected $table = 'pa_deposit_orders';

    protected $fillable = [
        'order_no', 'out_trade_no', 'merchant_id', 'platform_id',
        'chain', 'currency', 'amount', 'paid_amount', 'fee_amount', 'net_amount',
        'deposit_address', 'wallet_address_id', 'status', 'tx_hash', 'from_address',
        'confirmations', 'notify_url', 'notify_status', 'notify_times',
        'expired_at', 'paid_at', 'succeeded_at', 'extra', 'remark',
    ];

    protected $casts = [
        'merchant_id' => 'integer',
        'platform_id' => 'integer',
        'wallet_address_id' => 'integer',
        'confirmations' => 'integer',
        'notify_times' => 'integer',
        'extra' => 'array',
        'expired_at' => 'datetime',
        'paid_at' => 'datetime',
        'succeeded_at' => 'datetime',
    ];

    public static function tableSchema(): array
    {
        return [
            'table' => 'pa_deposit_orders',
            'comment' => 'USDT 入金订单',
            'columns' => [
                'id' => ['type' => 'bigIncrements', 'comment' => '主键'],
                'order_no' => ['type' => 'string', 'length' => 64, 'comment' => '平台订单号'],
                // ... 完整列定义见 doc/数据库设计.md
            ],
            'timestamps' => true,
            'columnComments' => [
                'created_at' => '创建时间',
                'updated_at' => '更新时间',
            ],
            'indexes' => [
                ['columns' => ['order_no'], 'unique' => true, 'name' => 'uk_order_no'],
                ['columns' => ['merchant_id', 'out_trade_no'], 'unique' => true, 'name' => 'uk_merchant_out_trade'],
                ['columns' => ['status', 'created_at'], 'name' => 'idx_status_created'],
            ],
            // 大数据量时可启用按月分区
            // 'partition' => ['column' => 'created_at', 'type' => 'monthly'],
        ];
    }
}
```

## 5. 金额处理

**禁止**：

```php
$total = $a + $b;  // float 精度问题
```

**推荐**：

```php
use app\support\Decimal;

$net = Decimal::sub($paidAmount, $feeAmount);
Decimal::cmp($amount, $minAmount) >= 0 or throw ...;
```

在 `app/support/Decimal.php` 封装 `bcadd` / `bcsub` / `bcmul` / `bcdiv` / `bccomp`（scale=6）。

## 6. 关联关系

```php
// DepositOrderModel
public function merchant()
{
    return $this->belongsTo(MerchantModel::class, 'merchant_id');
}

public function platform()
{
    return $this->belongsTo(PlatformModel::class, 'platform_id');
}

public function chainTransactions()
{
    return $this->hasMany(ChainTransactionModel::class, 'biz_id')
        ->where('biz_type', 'deposit');
}
```

## 7. 状态机守卫

状态变更集中在 Service，Model 仅提供常量与查询 scope：

```php
public function scopeStatus($query, string $status)
{
    return $query->where('status', $status);
}

public function canTransitionTo(string $next): bool
{
    return in_array($next, self::transitions()[$this->status] ?? [], true);
}
```
