## 一、通用约定

### 1.1 响应格式

**成功**：

```json
{
  "code": 200,
  "msg": "success",
  "data": {}
}
```

**失败**：

```json
{
  "code": 40001,
  "msg": "错误说明",
  "data": []
}
```

> 与现有工程一致：`code=200` 表示成功（见 `app/support/ErrorCode.php`）。

### 1.2 分页参数

| 参数 | 类型 | 默认 | 说明 |
|------|------|------|------|
| page | int | 1 | 页码 |
| limit | int | 20 | 每页，最大 100 |

**分页响应 data 结构**：

```json
{
  "list": [],
  "total": 0,
  "page": 1,
  "limit": 20
}
```

### 1.3 管理端认证

```
Authorization: Bearer {access_token}
```

登录、刷新 Token 见现有 `/admin/login`、`/admin/refresh`。

### 1.4 商户 API 认证

每个请求需携带：

| Header | 说明 |
|--------|------|
| X-Pay-Key | 商户 api_key |
| X-Pay-Timestamp | Unix 秒级时间戳 |
| X-Pay-Nonce | 随机字符串，16+ 字符 |
| X-Pay-Signature | 签名 |

**签名算法**：

```
payload = timestamp + "\n" + nonce + "\n" + method + "\n" + path + "\n" + raw_body
signature = HMAC-SHA256(payload, api_secret)  // hex 小写
```

- `path` 不含域名，如 `/api/pay/deposits`  
- `raw_body` 为空时仍保留末尾换行  
- 时间戳偏差超过 ±300 秒拒绝

## 二、错误码

### 2.1 系统通用（已有）

| code | 说明 |
|------|------|
| 200 | 成功 |
| 40101 | 未登录 |
| 40301 | 无权限 |
| 42201 | 参数校验失败 |
| 50000 | 服务器错误 |

### 2.2 充付业务（新增，建议 43xxx）

| code | 说明 |
|------|------|
| 43001 | 商户不存在或已禁用 |
| 43002 | API 签名无效 |
| 43003 | IP 不在白名单 |
| 43004 | 通道不可用 |
| 43005 | 金额低于最小限额 |
| 43006 | 金额超过最大限额 |
| 43007 | 商户余额不足 |
| 43008 | 订单不存在 |
| 43009 | 订单状态不允许此操作 |
| 43010 | 出金地址格式无效 |
| 43011 | 出金地址在黑名单 |
| 43012 | out_trade_no 重复（返回已有订单时 code 仍为 200） |
| 43013 | 链上广播失败 |
| 43014 | 确认数不足 |
| 43015 | 订单已过期 |

在 `app/support/ErrorCode.php` 中扩展常量与文案。

## 三、商户 Open API（/api/pay/*）

> 路由定义于 `config/routes/api.php`，中间件：`MerchantAuthMiddleware`、`MerchantIpMiddleware`。

### 3.1 创建入金单

```
POST /api/pay/deposits
```

**Body**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| out_trade_no | string | 是 | 商户订单号，最长 128 |
| platform_code | string | 是 | 如 TRC20_USDT |
| amount | string | 是 | 金额，6 位小数 |
| notify_url | string | 否 | 覆盖默认回调 |
| extra | object | 否 | 扩展 JSON |

**Response data**：

```json
{
  "order_no": "D202608191205000001",
  "out_trade_no": "M-ORDER-001",
  "chain": "TRC20",
  "currency": "USDT",
  "amount": "100.000000",
  "deposit_address": "TXxxx...",
  "status": "pending",
  "expired_at": "2026-08-19 12:35:00",
  "qr_content": "TXxxx..."
}
```

---

### 3.3 创建出金单

```
POST /api/pay/withdrawals
```

**Body**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| out_trade_no | string | 是 | 幂等号 |
| platform_code | string | 是 | |
| amount | string | 是 | 申请金额（内扣模式下含手续费计算基数） |
| to_address | string | 是 | 目标链上地址 |
| notify_url | string | 否 | |
| extra | object | 否 | |

**Response data**：

```json
{
  "order_no": "W202608191205000001",
  "out_trade_no": "M-W-001",
  "withdraw_amount": "50.000000",
  "fee_amount": "0.500000",
  "payout_amount": "49.500000",
  "to_address": "TXyyy...",
  "status": "reviewing"

```

### 3.4 查询出金单

```
GET /api/pay/withdrawals/{order_no}
GET /api/pay/withdrawals?out_trade_no=M-W-001
```

```
GET /api/pay/account/balance?platform_code=TRC20_USDT
```

**Response data**：

```json
{
  "currency": "USDT",
  "chain": "TRC20",
  "available": "10000.000000",
  "frozen": "50.000000"
}
```

### 3.6 Webhook 事件

商户需提供 HTTP(S) 接口接收 POST，返回 `2xx` 视为成功。

| event | 说明 |
|-------|------|
| deposit.detecting | 检测到链上转账 |
| deposit.success | 入金完成 |
| deposit.expired | 已过期 |
| deposit.failed | 失败 |
| withdraw.reviewing | 待审核 |
| withdraw.paying | 已广播 |
| withdraw.success | 出金完成 |
| withdraw.rejected | 审核驳回 |
| withdraw.failed | 失败 |
